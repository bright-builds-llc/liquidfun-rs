`*-VERIFICATION.md` reports, all 216 completed-plan summaries, all 108 v1
requirements, exact-head GitHub Actions evidence, and an independent

The material repository guidance was:

  oracle, provenance, and checkout-isolation conditions.

  renderer dependencies.
