# Roadmap: liquidfun-rs

## Overview

v1.3 Reference Testbed Scenes is archived. No milestone is active. Visitors can open the twelve missing JavaScript LiquidFun testbed scenes plus Hydraulic Fountain, Wave Tank, Liquid Bubbler, and Stacked Drip in the existing SolidJS playground. The six earlier scenes stay. Phase numbering continues after 33. Use `/gsd-new-milestone` when the next scope is chosen. This is not sealed C++ parity, a public benchmark, crate publication, or a git release tag.
