# Plan 08: CCD Candidate State Machine

## Objective

Build the private, deterministic continuous-collision candidate scanner and resumable world state around the existing time-of-impact implementation.

## Decisions Covered

- D-12: CCD is a private world state machine layered over the existing TOI implementation.
- D-13: TOI scanning, caching, eligibility, ordering, tentative advance, rollback, wake, bounds, and sub-step guards follow the pinned upstream behavior.

<threat_model>
- Reusing stale TOI cache entries after body/contact mutation could select an invalid event.
- Pointer-, hash-, or floating sort-based candidate selection could break source ordering and equal-time tie behavior.
- Tentative sweep advancement during candidate validation could leak into the world after rejection.
- Unbounded scans or sub-step counters could create denial-of-service behavior for adversarial worlds.
</threat_model>
