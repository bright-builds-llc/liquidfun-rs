### Layer colors **[UI-D86]**

- Rust: heavy `ParticleColor::new(251, 146, 60, 255)` (`#FB923C`), light `ParticleColor::new(59, 130, 246, 255)` (`#3B82F6`), one color per group, both opaque. `COLOR_MIXING` is never set (D-01), so each particle keeps its group color for the whole run and mixed regions read as interleaved orange and blue.
- Contrast against the `#071018` canvas (WCAG relative luminance, recomputed for this contract):

| Color | Unshaded | At the 0.73 density-shade floor |
|-------|----------|---------------------------------|
| `#FB923C` heavy | 8.46 | 4.69 |
| `#3B82F6` light | 5.21 | 3.09 |
| `#94A3B8` tank stroke (existing) | 7.47 | n/a (segments are not shaded) |

- Both layers stay at or above 3:1 against the canvas even fully packed. Their mutual luminance contrast is low (1.63 unshaded, 1.52 both at the floor), so the layers separate by **hue**: orange and blue are complementary and the standard color-vision-deficiency-safe pair. Packing at the tank bottom (strongest at ratio 3, Research Pitfall 4) darkens the blue toward its floor, which only widens the gap to the orange above it.
- Why these values: `#FB923C` is warm, clearly orange and distinct from the `DRIP` amber `#F2B040`; `#3B82F6` is the deepest blue that keeps 3:1 at the floor (`#2563EB` drops to 2.35) and reads darker and more saturated than the shared `#4DA3FF` water, so the light layer is not mistaken for the default water.
- Web preview: add to `web/src/catalog/preview-kit.tsx`, after `FERRO`:
  - `/** Rayleigh–Taylor heavy layer; matches the Rust particle color. */ export const RT_HEAVY = "#FB923C";`
  - `/** Rayleigh–Taylor light layer; matches the Rust particle color. */ export const RT_LIGHT = "#3B82F6";`
- Four-mode check (D-12), recorded in the phase summary before close: Shaded blob (default), GPU Water, circle wireframe (README clip) and the static preview. Pass rule: at default zoom on desktop and in the 390 × 844 portrait viewport, the flat interface, every finger and the overturned end state show orange and blue as two distinct layers, and both are distinguishable from the canvas. The weakest expected case is thin blue wireframe rings in the README clip; check it explicitly. If the blue fails a mode, lighten it in the same hue to `#4B8DF8` (never to the accent or water `#4DA3FF`); if the orange fails, deepen toward `#F97316` (6.83 / 3.88). Change the Rust color and `RT_*` in the same commit. Foam whitening in GPU Water (above 3.5 m/s) on fast fingers at ratio 3 is acceptable and recorded, not a blocker (Research Pitfall 10).
