# Plan 04-02: Matrices, Transforms, and Sweeps

<objective>
Complete the public math surface with initialized matrices, rotations, transforms, and invariant-bearing sweeps while preserving pinned expression order and edge-case behavior.
</objective>

<threat_model>
### Trust boundaries

| Boundary | Untrusted input | Required validation |
| --- | --- | --- |
| `Sweep::new` and `advance` | Caller vectors, angles, and time fractions | Require finite fields, `alpha0/alpha` in `0.0..=1.0`, and nondecreasing time; fail without mutation. |
| Matrix/transform constructors | Caller-provided float columns/angles | Always initialize storage; expose no raw layout or unchecked access. |

### STRIDE register

| Threat ID | Category | Component | Disposition | Mitigation plan |
| --- | --- | --- | --- | --- |
| T02-1 | Tampering | `Sweep` state | Mitigate | Task 2 uses private fields and checked construction/advance with state-preservation tests on failure. |
| T02-2 | Elevation of privilege | Matrix/transform representation | Mitigate | Task 1 omits `repr(C)`, raw slices, unchecked indexing, unsafe code, and public field mutation. |
| T02-3 | Denial of service | Matrix/sweep kernels | Accept | All operations are bounded allocation-free arithmetic with no data-dependent unbounded iteration. |
</threat_model>

Do not call `sin_cos`, `mul_add`, or reassociate formulas. Document column-major semantics without `repr(C)`/raw layout promises. Implement private-field `Sweep { local_center, c0, c, a0, a, alpha0 }` with a checked public constructor requiring every vector/angle finite and `alpha0` in `0.0..=1.0`. Add typed errors for non-finite, decreasing, or out-of-range fractions. Preserve exact kernels: transform position `p = (1.0 - beta) * c0 + beta * c`; angle `(1.0 - beta) * a0 + beta * a`; set rotation from that angle; then `p -= rotation * local_center`. Advance requires `alpha0 < 1.0`, computes `beta = (alpha - alpha0) / (1.0 - alpha0)`, then `c0 += beta * (c - c0)`, `a0 += beta * (a - a0)`, and finally `alpha0 = alpha`. Normalize computes `d = TAU * floor(a0 / TAU)`, then subtracts `d` from both `a0` and `a`; do not individually wrap either angle. Expose read-only accessors and transform-at-fraction. Add public integration tests for exports, identity, sweep endpoints, monotonic advance, invalid-state rejection without mutation, tau normalization, and bounded well-conditioned round trips. Use proptest only for bounded finite domains and keep one concern per test.
  </action>
