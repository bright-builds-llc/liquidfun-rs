## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser storage → shell | Getter, reads and writes may throw; values are untrusted and may come from another tab, a newer build, or tampering. |
| other tab ↔ this tab | Concurrent writers share one key. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-10 | Tampering (data destruction) | write path | mitigate | Degraded mode returns before any `setItem`; startup and re-read parse failures degrade instead of "repairing"; probe uses a separate key (Pitfall 7). Unit tests assert the seeded value is byte-identical. |
| T-41-11 | Denial of service | storage exceptions | mitigate | Every storage access is in its own `try`; failures switch to degraded mode and the game continues in memory; nothing propagates into the edit or run paths. |
| T-41-12 | Tampering (star loss) | concurrent tabs | mitigate | Re-read + `mergeProgress` before each write; stars only ever merge upward. |
| T-41-13 | Information disclosure | stored data | accept | Only stars, a percentage, a level hash and integer poses are stored; no personal data or secrets. |
</threat_model>
