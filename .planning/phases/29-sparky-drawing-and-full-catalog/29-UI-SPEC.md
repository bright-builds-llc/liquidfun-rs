|-------|-----|----------------|
| Water | `#4DA3FF` | Drawing water strokes; preview water marks |
| Elastic clump | `#3DDC97` | Drawing elastic strokes; one preview clump |
| Spark red | `#F87171` | Spark burst cycle, preview burst dots |

Spark color cycle, in ring-slot order, alpha held at 255:

1. `#F87171` → `ParticleColor::new(248, 113, 113, 255)`
1. `#3DDC97` → `ParticleColor::new(61, 220, 151, 255)`
1. `#39D3C7` → `ParticleColor::new(57, 211, 199, 255)`
1. `#F4F7FA` → `ParticleColor::new(244, 247, 250, 255)`

Fade writes `channel = original * coeff` in one Rust batch per burst per step. Alpha stays 255. A burst created with `ParticleColor::ZERO` is a contract miss: the copied color lane must exist and must darken before the group is destroyed. Drawing water stays `#4DA3FF`. Drawing elastic stays `#3DDC97` for the whole joined stroke so the non-water material is visible before the clump settles.

## Player Interaction Contract

### Drawing Particles (FX-02)

| Concern | Contract |
|---------|----------|
| Opening frame | Empty vessel. Floor, side walls, and ceiling strip visible. Particle count is 0. No empty-state overlay once the first frame is ready. Particle radius about 0.05 |
| Paint | Pointer down and pointer move each destroy particles inside a circle of radius 0.2, then create a group at the unprojected point. A click with no move leaves one stamp. Pointer up clears the joined group. A stamp on an unpaired pointer-up is acceptable for the README cue; a pointer-up that ends a drag only clears |
| Outside the vessel | Same destroy-then-create at the unprojected point |
| Join | Consecutive samples join the previous group only while the group flags still match. A destroyed or empty group clears the join |
| Water | `ParticleFlags::WATER`, empty group flags, color `#4DA3FF`. The stroke flows |
| Elastic | `ParticleFlags::ELASTIC`, `ParticleGroupFlags::SOLID`, color `#3DDC97`. The stroke clumps |
| Cursor | Existing crosshair via `canvas-interactive` while playing or paused |
| Reset | Disposes the session, clears the join, restores `water`, returns an empty vessel at the current Gravity |
| Particle cap | Stop creating at the existing 10240 maximum. A failed create is a no-op sample |
| Verification attribute | Publish `data-particle-count` on `<main>` from the current frame particle count so smoke can read it. The first ready Drawing frame is `0`. After one drag it is greater than `0` |

### Sparky (FX-01)

| Concern | Contract |
|---------|----------|
| Opening frame | Six dynamic circles in a tall chamber. Circle radius 2. Particle radius 0.25. Walls are visible. Circles are the sparkable bodies; walls are not |
| Motion | Watch-first. Circles fall and collide. Play scene, Pause scene, and Reset scene are the controls besides Gravity |
| Sparks | A new body contact where at least one fixture is a sparkable circle throws one powder burst at the contact. Persistent resting contact throws nothing. A step with at least one new sparkable contact throws at least one burst |
| Burst look | Powder group, splash radius 1.5 m, outward velocities, lifetime **0.75 s** (inside the locked 0.5–1 s band, deterministic). Colors follow the four-color cycle and fade toward black with alpha 255 |
| Pool | Ring length 16. Reusing a slot destroys the previous group first. Particle count stays bounded across repeated contacts |
| Pointer | `apply_pointer` is a no-op. The shared crosshair class may stay. A pointer poke is out of this phase |
