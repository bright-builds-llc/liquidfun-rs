## Page Structure and Layout

Use the shipped `PlaygroundShell`. Do not restore CatalogNav, a separate catalog page, or a three-column card grid.

Primary focal point on a ready scene is the live canvas viewport. Chrome (header, demo list, playback) is secondary. When the drawer or sidebar is the active surface, catalog-list focus stays supporting.

Semantic order on every view:

1. Sticky `SiteHeader` with `h1#site-title`, page summary, `GitHub source`, and mobile `Demos` trigger (hidden ≥769px).
1. `.app-body` with:
   - desktop `<aside class="demo-sidebar">` containing `DemoNavigation` (`aria-label="Demos"`);
   - `<main class="playground-main">` containing the shared player or fallback only.
1. `SiteFooter` with source, FOSS, maintainer, and provenance chrome.
1. On viewports `max-width: 768px`, the sidebar is `display: none`. The same `DemoNavigation` also renders inside the Kobalte `Dialog` named `Demos`.

Desktop contract (≥769px viewport width):

- Center `.app-shell` at `max-width: 1440px` with 24px padding.
- Sticky header; sticky 280px sidebar with `max-height: calc(100vh - 156px)` and internal `overflow-y: auto`.
- Main column is `minmax(0, 1fr)`.
- Catalog scroll happens in the sidebar, never by making the canvas a touch trap.

Mobile contract (≤768px):

- One-column body. `Demos` trigger visible, 44px min block size.
- Drawer width `min(320px, 88vw)`, overlay `#000000` at 72% opacity, focus trap / Escape / overlay / selection close unchanged.
- Compact previews appear in the drawer list, not a second layout.

Do not add a marketing hero, search, filters, scene editor, live WASM thumbnails, or a second page heading.

Source: `26-CONTEXT.md` D-01 / D-03, `20-UI-SPEC.md` Page Structure.

## State and Interaction Contract

| State | Visible treatment | Behavior |
|-------|-------------------|----------|
| Loading | `Loading {Scene name}…`; muted status; identity visible; loading overlay; Play/Pause/Reset, scene controls, and canvas gestures disabled; Retry hidden | Await generated initializer, construct the selected scene, validate a frame, and draw it before leaving this state |
| Playing | `Playing`; accent status dot; live viewport; Pause and Reset enabled; Play disabled; Retry hidden; scene controls enabled only when present | Advance the current session with Phase 17 ownership caps |
| Paused | `Paused`; muted status; last frame retained; Play and Reset enabled; Pause disabled; Retry hidden | Freeze without disposing |
| Failure | `{Scene name} failed`; destructive status and error copy; Retry and Reset enabled; Play/Pause, scene controls, and canvas gestures disabled | Retry/Reset recreate from documented initials |
| Fallback | Fallback heading and body; no live session; `Open Dam Break` enabled; Play/Pause/Reset/Retry, scene controls, and canvas hidden | Do not construct a WASM world |

Focus: 2px solid `#39D3C7` `:focus-visible` with 4px offset on **buttons, selects, and in-page links**, including demo-nav links. Do not add a second focus system.

Catalog interaction: each shipped demo link is keyboard-operable. Visiting a shipped scene hash starts that scene.
