# Phase 20 — UI Design Contract

> Visual and interaction contract for compact in-app catalog previews inside the Kobalte playground shell, plus honest live-control labels after Reset. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

Reuse the shipped dark playground tokens, type scale, 44px hit targets, `#39D3C7` 2px / 4px focus ring, PlaygroundShell layout, labeled scene controls, player states, credits, and footer. This phase restores static SVG previews inside existing `DemoNavigation` list items and makes preset `<select>` labels match the rebuilt world after Reset. It does not adopt a component library, revive `.catalog-card`, or restyle `SceneControls`.

18-UI-SPEC / 19-UI-SPEC **page structure** (three-column cards, nested `Open` CTA, 960px single column) is superseded by the owner-approved 2026-09-19 Kobalte shell. **Preview art direction, `Static preview` honesty, control labels, and dark tokens** still apply.

Do not change WEB-04 control sets, Apply-setting copy, or native reset physics/WASM constructors.

## State and Interaction Contract

| State | Visible treatment | Behavior |
|-------|-------------------|----------|
| Loading | `Loading {Scene name}…`; muted status; identity visible; loading overlay; Play/Pause/Reset, scene controls, and canvas gestures disabled; Retry hidden | Await generated initializer, construct the selected scene, validate a frame, and draw it before leaving this state |
| Playing | `Playing`; accent status dot; live viewport; Pause, Reset, scene controls, and canvas gestures enabled; Play disabled; Retry hidden | Advance the current session with Phase 17 ownership caps |
| Paused | `Paused`; muted status; last frame retained; Play, Reset, scene controls, and one-shot canvas downs enabled; Pause disabled; Retry hidden | Freeze without disposing. Do not remount scene controls. |
| Failure | `{Scene name} failed`; destructive status and error copy; Retry and Reset enabled; Play/Pause, scene controls, and canvas gestures disabled | Retry/Reset recreate from documented initials and remount honest selects |
| Fallback | Fallback heading and body; no live session; `Open Dam Break` enabled; Play/Pause/Reset/Retry, scene controls, and canvas hidden | Do not construct a WASM world |

Focus: 2px solid `#39D3C7` `:focus-visible` with 4px offset on **buttons, selects, and in-page links**, including demo-nav links that now contain previews. Do not add a second focus system.

Catalog interaction: each shipped demo link is keyboard-operable. Visiting a shipped scene hash starts that scene.
