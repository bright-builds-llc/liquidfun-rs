- Frame per step: `frame = GravityFrame::from_gravity(world.gravity())`; no frame means no force. For particle `p` and magnet `m`: `r = p - m`, `h = r.up` (dot product written out), `s = r.across`.
- Potential `Psi = G * S * L * E(h) * R(s) * M(s)`; acceleration = its gradient: `a_up = G*S*L * E'(h) * Q(s)`, `a_across = G*S*L * E(h) * Q'(s)`, `Q = R * M`, `Q' = R' * M + R * M'`; then clamp `|a| <= CAP * G * S`.
- Pieces (no transcendental calls; only + - * /, `abs`, `round`, `signum`, and `length()`): `bump(x) = (1 - x^2)^2` for `|x| < 1` else 0 (this is `E'(h)` with `x = h / H`); `bump_integral(h, H) = H * (x - 2x^3/3 + x^5/5)` for `|x| < 1` else `signum(h) * 8H/15`; envelope `R(s) = bump(s / W)` with `R'(s) = 2(1 - y^2) * (-2s / W^2)`; columns `u = s / lambda; t = u - u.round(); b = 1 - 4t^2; b2 = b*b; M = b2*b2; M' = 4*b2*b*(-8t)/lambda`. Copy the research "Code Examples / Field" snippet.
