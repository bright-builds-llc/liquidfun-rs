Provenance contract:

```typescript
export type BuildInfo = {
  readonly version: string;
  readonly commitLabel: string;
  readonly maybeCommitUrl: string | undefined;
  readonly buildLabel: string;
  readonly maybeBuildUrl: string | undefined;
};

export function readBuildInfo(env?: {
  readonly VITE_APP_VERSION?: string;
  readonly VITE_GIT_SHA?: string;
  readonly VITE_BUILD_ID?: string;
  readonly VITE_BUILD_URL?: string;
}): BuildInfo;
```

Missing or blank fields become the exact string `Unavailable`. A 40-char lowercase hex SHA becomes a 7–12 char `commitLabel` and `maybeCommitUrl` `https://github.com/bright-builds-llc/liquidfun-rs/commit/{fullSha}`. `maybeBuildUrl` is set only when `VITE_BUILD_URL` is an `https://github.com/bright-builds-llc/liquidfun-rs/actions/runs/` URL.
