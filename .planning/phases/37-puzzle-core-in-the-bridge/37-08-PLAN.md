Fixture format (D-18), shared byte-for-byte by the Rust and TS parsers:
```
level first-pour
placement plank 8 64 23
outcome won
outcome_step 412
final_count 640
```
Rules: lines end with `\n` (one trailing newline allowed, no blank lines, no `\r`, no comments); single spaces between tokens; line 1 is `level <id>` (allowlisted); then zero or more `placement <kind-token> <x> <y> <angle>` with integers matching `-?[0-9]+`; then either nothing (input-only, used for recording) or exactly `outcome <won|lost>`, `outcome_step <[0-9]+>`, `final_count <[0-9]+>` in that order. Anything else is an error `fixture line N: ...` (1-based). `final_count` is the frame goal count at `outcome_step`.
